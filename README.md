# EndlessRunner

Endless Runner Game for Mobile, written in C#/Unity.

![Screen shots](https://github.com/GunnarKarlsson/EndlessRunner/raw/master/Screenshots/ss1.png)

## Gameplay

On Mobile, swipe left / right to move sideways. Swipe up to jump.

In Unity editor, swipe left, right, up with left mouse button pressed.

Avoid obstacles and flying crates.

## Other
Tested on Samsung S8+ running Android 7.
