# EndlessRunner

Endless Runner Game for Mobile.

## Gameplay

On Mobile, Swipe Left / Right to move sideways. Swipe up to jump
In Unity editor, swipe Left, Right, Up with Left mouse button pressed.
Avoid obstacles and flying crates.

## Other
Player character is from "Free Voxel Girl" asset: https://assetstore.unity.com/packages/3d/characters/humanoids/free-voxel-girl-95532
